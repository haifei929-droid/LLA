# P0 前端手动验收清单（Spec 31.9 / 26）

> 与自动化测试互补：自动化锁定 API 与状态机，本清单锁定真实页面操作体验。
> 验收环境：`http://127.0.0.1:5173`（前端 Vite + 后端 FastAPI，主库）。

## 0. 准备
- [ ] 打开首页：3 秒内看清「上次做到哪里 / 推荐下一步 / 累计与本周状态」三件事（31.9）
- [ ] 页面为色块 + 数字 + 状态符号风格；无课程卡片、金币、星级、打卡火焰等元素（26）

## 1. 首页
- [ ] 进行中的素材排在「已完成」素材之前
- [ ] 累计学习分钟数随训练增长（对照时间日志）
- [ ] 周测 Gate 卡片可进入周测页
- [ ] 素材完成态出现「获取下一篇素材」按钮（搜索中显示等待提示）

## 2. 素材训练页
- [ ] 盲听态：提示「不显示字幕/原文/关键词」，音频可完整播放，按钮在听完后可用
- [ ] 理解检查：四档自评可选（<30% / 30–50% / 50–70% / >70%），概述必填
- [ ] 听写态：**页面不出现句子原文**；播放按钮计遍数；第 1 遍输入框禁用
- [ ] 输入 `____` 占位可用；提交后错误按色块语义区分（漏听红 / 听错橙 / 词形紫 / 拼写黄 / 主动留空灰），只显示类型与位置、不显示答案
- [ ] 提示（位置→长度+首字母）、Reveal（显示原文并要求复写提交）流程可用；Reveal 后句子仍须逐字正确才能通过
- [ ] 句级播放定位正确（点击「播放本句」听到的是当前句）
- [ ] 二次复听态显示原文（此时可看），完成后进入朗读
- [ ] 朗读态：大文本 + 原音播放 + 录音（需麦克风授权）+ 段尾三维反馈（语速/停顿/重音各自 PASS/CLOSE/FAIL，**不是综合平均**）
- [ ] 三维全 PASS 才显示「完成」；未达标提示对应维度重练
- [ ] 全文验收：读全文，PASS 后素材标记完成；失败时回到对应 Part 复练
- [ ] 任何状态都可点「跳过此素材，换一篇」→ 素材被跳过并自动搜索替代

## 3. 周测 / 强化
- [ ] 周测页可创建本周周测；测试类型与当周训练匹配（无朗读训练则只有听写测试）
- [ ] 听写测试逐句完成，全部提交后自动评分（exact 比例）
- [ ] 分数 <80% → Gate 未通过 → 「开始强化训练」可用
- [ ] 强化包句子全部逐字正确后 Gate 恢复「已通过」并提示可进入下一轮
- [ ] 朗读周测（当周有朗读训练时）读一段素材，评分后记录

## 4. 异常与恢复
- [ ] 刷新页面后训练位置不丢失（恢复到具体 Part / 句子 / 尝试次数）
- [ ] 后端未启动时页面给出明确提示，不白屏
- [ ] 搜索素材断网/失败时显示错误信息，不破坏当前训练状态
- [ ] 录音中途停止不产生 PASS 记录；录音文件保留可重试

## 5. 风格一致性
- [ ] 完成=绿、进行中=蓝/深、未解锁=灰、错误=红、接近达标=黄、拼写问题=黄、主动留空=灰，全局一致
- [ ] 朗读反馈无逐词实时红绿（Spec 26：朗读不逐词打分）
- [ ] 移动端（窄屏）不破版（矩阵与色块单列堆叠）
